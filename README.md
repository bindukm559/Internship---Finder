# Internship Finder – Project 1

## Project Type

Responsive Frontend Interface

## Technologies

- HTML5
- CSS3
- JavaScript
- No framework

## Project Process

1. Discovery / Research
2. Wireframe
3. Semantics
4. Style
5. Logic
6. Audit

## Main Features

- Responsive mobile-first layout.
- Internship search.
- Category filtering.
- Duration filtering.
- Save internships.
- Local storage.
- Mobile navigation.
- Internship details.
- Accessible semantic structure.

## Run

1. Open the folder in VS Code.
2. Open index.html.
3. Install Live Server.
4. Right-click index.html.
5. Select Open with Live Server.

The internship listings are sample frontend data for demonstrating the interface. They are not verified real internship listings.
