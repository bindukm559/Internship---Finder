# Discovery / Research

## Project

Internship Finder – Responsive Frontend Interface

## Target User

College students looking for internship opportunities.

## Research Question

How might we make internship discovery easier and clearer for students on mobile devices?

## Empathy Map

### Says

- I want to find a suitable internship.
- I want important information to be easy to find.
- I want a simple interface.

### Thinks

- Which internship is suitable for me?
- What skills are required?
- What is the duration?
- Is it remote or on-site?

### Does

- Searches for internships.
- Browses categories.
- Reads internship details.
- Saves interesting internships.

### Feels

- Confused when there is too much information.
- Frustrated when navigation is difficult.
- More confident when information is clearly organized.

## Pain Points

1. Too much information can confuse students.
2. Important internship details may be difficult to find.
3. Navigation can be difficult.
4. Students need a mobile-friendly interface.
5. Students need simple search and filtering.

## How Might We?

How might we create a simple responsive internship finder that helps students quickly discover relevant opportunities?

## Design Response

- Simple navigation.
- Search functionality.
- Category filtering.
- Duration filtering.
- Clear internship cards.
- Save functionality.
- Mobile-first responsive layout.
- Semantic HTML and accessibility.
